# 🤖 Google API 计费终极指南：从零基础到 100% 安全防范（Gemini & GCP）

## ⚠️ 写在最前：开发者的三大焦虑

当一个开发者（尤其是刚入门的小白）同时使用 Google Play 和 Google Cloud Platform (GCP) 上的 Gemini API 时，往往会对“账单”产生三大焦虑：

1.  **“骚扰”焦虑：** Google 绑定了我的信用卡和法定地址，会不会给我邮寄**纸质账单**到家里来？
2.  **“破产”焦虑：** 我只是用 API 做点小测试，万一代码写错，如何 100% 避免“一觉醒来，房子归 Google”的天价账单？
3.  **“混淆”焦虑（最核心的陷阱）：** `Gemini Advanced`、`AI Studio`、`Gemini API` 到底有啥区别？我订阅了会员，为什么用 API 还要钱？

本文档将用最通俗易懂的方式，一次性彻底解决这三个问题，为你提供一套从“零基础”到“付费大神”的安全操作全流程。

---

## 🧾 第一部分：“纸质账单”焦虑？一分钟彻底搞懂 Google 账单

### 核心结论：普通用户绝对、永远不会收到纸质账单

无论 Google Play 还是 Gemini API，Google 对普通开发者和用户的默认账单形式都是**电子账单**。

---

### 1. Google Play 商店（应用、游戏购买）

* **账单形式：电子收据。** 每次购买后，系统会立即发送电子邮件收据到你的 Google 账号邮箱。
* **在线记录：** 你可以随时在 [Google 支付中心 (Google Payments)](https://payments.google.com/) 查看所有历史记录。
* **【小白释疑】为何要我填法定地址？**
    * 这是很多人的焦虑点。Google 要求提供法定地址是出于**税务和金融法规**要求（例如，确认你所在的国家/地区以计算正确的税率），**这不代表**会向该地址邮寄纸质账单。

### 2. Gemini API / Google Cloud (GCP)

* **账单形式：电子账单。** 你的所有 API 费用都通过 Google Cloud Billing 结算。账单（PDF）会定期发送到你 Billing 账号关联的电子邮件。
* **唯一的例外（与你无关）：** 只有申请并获批使用 **“月度账单结算 (Invoicing)”** 的极大型企业客户（比如世界 500 强），才可能涉及纸质邮寄。

---

### 【小白释疑】什么是“US$100.00 起付金额”？

这是你开启“即用即付”后会看到的，它叫**“自动扣款阈值” (Threshold Billing)**。

* **小白比喻：** 把它想象成“酒吧记账”。
    * 你绑定了信用卡，但 Google（酒保）不会你每调用一次 API（喝一口酒）就刷一次卡。
    * Google 会等你**累计消费**达到了 $100（你的“记账额度”），**或者**到了月底（酒吧关门结账），以**先到者为准**，再一次性从你卡里扣费。
* **如何确认你是这种模式？**
    1.  前往 Google Cloud 的 [付款概览页面](https://console.cloud.google.com/billing/payment/overview)。
    2.  你会看到你的付款方式是 **“自动付款” (Automatic payment)**。
    3.  **看到这个词，就 100% 意味着你是“电子账单”，绝不会收到纸质账单。**

## ☁️ 第二部分：【核心】防止“费用冗余”，彻底厘清产品与计费

这是导致一切混淆和“额外花费”的根源。你必须先搞懂你在用什么。

### 2. 结论：我该用哪个？

* **如果你是普通用户，想和最强的 2.5 Pro 聊天：**
    * **选择：** 订阅 **Gemini Advanced (网页版)**。
    * **原因：** 这是为消费者设计的，按月付费，不限制 token 数量（但在高速使用下有限制）。**这和 API 无关，也不会支付 API 费用。**

* **如果你是开发者，想免费测试 2.5 Pro 的 API 功能：**
    * **选择：** 使用 **Google AI Studio 网页 (免费原型模式)**。
    * **原因：** 可以在不付费的情况下，在网页上测试几个提示词 (Prompt)，但要准备好很快达到速率限制 (5 RPM)。

* **如果你是开发者，准备在你的应用中正式使用 2.5 Pro：**
    * **选择：** 使用 **Gemini API (即用即付)**，并在 AI Studio 中关联你的 Google Cloud 账单。
    * **原因：** 这是唯一能获得高配额、稳定服务的方式。你将为你的每一次 API 调用付费。

### 3. 【小白释疑】三个关键的“计费状态”

上面讲的是“产品”，下面讲的是“计费状态”。

1.  **免费套餐 (Free Tier)**
    * **对应产品：** `Gemini API (Free Tier)`。
    * **限制：** 速率极低，且有每日总数限制（`...per day`）。
    * **费用：** 永不付费。用完即停。

2.  **免费试用 (Free Trial)**
    * **这是什么？** 这是你新注册 Google Cloud 时，Google 赠送给你的一笔**信用额度**（例如 $300 赠金，有效期 90 天）。
    * **限制：** 在试用期间，你**不再受“免费套餐”的每日限制**！你将立刻升级到“即用即付”用户的高配额（例如 150+ RPM）。
    * **费用：** 你所有的使用都会被计费，但费用会**从 $300 赠金中自动扣除**。

3.  **即用即付 (Pay-as-you-go)**
    * **这是什么？** 这是指你的“免费试用”已结束，或者你主动升级，你的项目正式绑定了信用卡，开始为你的**所有用量**付费。
    * **⚠️ 这是最危险的误区！** 开启“即用即付”后，你**不再享有“免费套餐”的每日免费额度**。
    * **换句话说，换成“即用即付”后，就没有所谓的“免费额度”了。**
    * 你的账单将**从 $0.00 开始计算**，你使用的**第一个请求、第一个令牌**都会被计入账单。
    * **限制：** 你获得了很高的 API 配额（如 150+ RPM），唯一的“限制”就是你的预算。

## 🛠️ 第三部分：终极费用控制指南（三层保险丝）

当你理解了第二部分，知道自己必须为 API 付费后，你就可以通过这三层保险丝来 100% 控制成本。

### 第一层保险（技术）：设置 API 配额（防突发）

这是你的**“技术保险丝”**，用于防止代码死循环等**突发性**错误。

* **【关键澄清：这是“每分钟”限制】**
    开启“即用即付”后，免费套餐的 `...per day` (每日) 限制被移除。你需要设置的是**更精细、更安全**的**“每分钟”**限制，即 `Requests per minute` (RPM)。
    
    “每分钟”限制远比“每日”限制更安全。一个出错的脚本可能在 5 分钟内就跑满“每日”限额；但如果设置了“每分钟 100 次”的限额，它在第 1 分钟的第 101 次调用时就**立即被阻止**，将损失降到最低。

* **详细操作步骤：**
    1.  前往 Google Cloud API 配额页面：
        * **直达链接 (通用)：** [https://console.cloud.google.com/apis/api/generativelanguage.googleapis.com/quotas](https://console.cloud.google.com/apis/api/generativelanguage.googleapis.com/quotas)
    2.  在页面顶部的项目下拉菜单中，**确保你选择的是你自己的项目**。
    3.  在“过滤”框中，输入 `generativelanguage.googleapis.com` (Gemini API)，确保只看它的配额。
    4.  找到 `Requests per minute` (每分钟请求数) 相关的配额项（例如 `gemini-2.5-pro` 模型的 `Requests per minute`）。
    5.  **选中**你想要限制的配额项前面的复选框。
    6.  点击页面顶部的 **“修改配额” (EDIT QUOTAS)** 按钮。
    7.  在右侧弹出的窗口中，输入你想要的**新限额**（例如 **100**），然后点击“下一步”并“提交请求”。

### 第二层保险（财务）：设置“预算和提醒”（防超额）

这是你的**“财务保险丝”**，用于监控你的**总花费**。

* **【关键澄清：这是“月度”限制】**
    Google Cloud 的预算是围绕**月度 (Monthly)** 结算周期设计的。你设置的是一个**月度总预算**（例如 $10），**不能**设置“每日 $1”这样的重复预算。不过，它的监控和提醒是**实时**的。

* **详细操作步骤：**
    1.  前往 Google Cloud Console 的 **“结算” > “预算和提醒”** 页面。
        * **直达链接：** [https://console.cloud.google.com/billing/budgets](https://console.cloud.google.com/billing/budgets)
    2.  点击 **“创建预算” (CREATE BUDGET)**。
    3.  **第 1 步 (范围)：** 保持默认设置（“项目”选你的项目，“服务”选“所有服务”），点击“下一步”。
    4.  **第 2 步 (金额)：** 选择“预算类型”为 **“指定金额”**，然后在“目标金额”处输入你心理上能接受的小额度，例如 **$10**。点击“下一步”。
    5.  **第 3 步 (操作)：** 这是最关键的一步！
        * **A. 设置邮件提醒（必做）：**
            * 在“提醒阈值”下，系统默认有 50%, 90%, 100%。
            * 确保 **“电子邮件提醒”** 下的选项被勾选为 **“向结算管理员和用户发送提醒”**。
            * **效果：** 当你这个月花费达到 $5, $9, $10 时，你会立即收到邮件警告。
        * **B. 设置终极保险丝（可选，但强烈推荐）：**
            * 在“管理通知”下，选择 **“将 Pub/Sub 主题与此预算关联”**。
            * 你可以通过这个功能，关联一个 Cloud Function，实现在**“账单达到 $10 时，自动关闭此项目的结算功能”**。
            * **注意：** 这需要一点点高级设置，但这是唯一能 100% 自动停止 API 的方法。
    6.  点击“完成”。

### 第三层保险（支付）：主动“人工付款”（控频率）

这是针对那个 “$100 自动扣款阈值” 太高而设计的**“支付频率保险丝”**。

* **目的：** 默认 $100 才扣款一次，你可能感觉不踏实。你可以通过“主动付款”，强行把这个周期变短，比如 $10 就付一次。
* **详细操作步骤：**
    1.  当你收到第二层保险（例如 $10）的**预算提醒邮件**后，登录 Cloud Billing **“付款概览 (Payment overview)”** 页面。
        * **直达链接：** [https://console.cloud.google.com/billing/payment/overview](https://console.cloud.google.com/billing/payment/overview)
    2.  你会看到“您当前的余额” (Your current balance) 显示为 $10 (或你实际的花费)。
    3.  点击 **“进行付款” (Make a payment)** 按钮。
    4.  手动支付这 $10 的欠款。
    5.  **好处：** 支付完成后，你的 $100 自动扣款阈值会**重置**（你的欠款清零了，重新开始累计）。这样你就成功地将一次 $100 的大额扣款，分解成了一次 $10 的小额支付。

## ⛔ 第四部分：额外警惕！小心 GCP 的其他“吸费陷阱”

Google Cloud 是一个庞大的平台。即使你只想用 Gemini API，你也要小心不要在控制台里“不小心”点开了其他付费服务。

最常见的“陷阱”包括：

1.  **Compute Engine（虚拟机）：**
    * **小白释义：** 一台 7x24 小时开机为你工作的**虚拟电脑**。
    * **陷阱：** 你可能因为好奇“创建了一个 VM 实例”，然后忘记关掉它。它会**按小时或按秒**持续计费，是“天价账单”的重灾区。
2.  **Cloud Storage（云存储）：**
    * **小白释义：** 一个**网络硬盘**（像 Google Drive）。
    * **陷阱：** 你随手上传了一个大文件（如视频、数据集）并忘记删除。这会产生**存储费**和（可能的）**下载流量费**。
3.  **Vertex AI（企业级 AI 平台）：**
    * **小白释义：** Gemini API 的**“企业豪华版”**。
    * **陷阱：** 它的计费更复杂（例如可能按“节点小时”收费）。如果你只是个人开发者，请坚持使用我们上面设置的 `generativelanguage.googleapis.com` 这个简单的 API，**不要**去 Vertex AI 页面“启用端点”或“训练模型”。

## ✅ 总结：给开发者的最安全路径（终极清单）

1.  **【认清产品】** 查看第二部分的“产品对比表”，明确你要用的是“网页版订阅”、“AI Studio 测试”还是“API 即用即付”。
2.  **【认清现实】** 如果你用的是 API，请接受：
    * 网页版订阅 (`Gemini Advanced`) 和 API 付费**完全无关**。
    * 升级到“即用即付”后，**就没有免费额度**了，每一分钱都会计费。
3.  **【立刻！】** 前往“API 配额”页面，将 **RPM（每分钟请求数）** 主动调低到 100 左右（第一层保险）。
4.  **【立刻！】** 前往“结算”页面，设置一个 **$10 的月度预算提醒（和自动停止操作）**（第二层保险）。
5.  **【按需】** 当收到 $10 预算提醒邮件后，**主动去“人工付款”**，避免触发 $100 的自动扣款（第三层保险）。
6.  **【自律！】** **只使用 Gemini API**，不要在控制台里乱点 Compute Engine、Vertex AI 等你不知道的服务。
